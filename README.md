# Team Website

Our club/business website: plain HTML and CSS, hosted on GitHub Pages.

## Working on it
1. `git pull` to get the latest `main`.
2. `git checkout -b your-change-name`
3. Make changes (with Claude Code, which follows `CLAUDE.md`).
4. Commit, push, and open a pull request for the other person to review.

## Preview locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.
