# Shared files

Everything a teammate's Claude session receives or produces goes here, so the whole team can see it.

- `uploads/`: files someone uploaded to their session (data, documents, images), unchanged.
- `outputs/`: reports, exports, and other files a session generated.

Name files by date and topic, e.g. `uploads/2026-10-31-member-list.xlsx` or `outputs/2026-10-31-integrity-report.md`.

This repository is public: don't put private or unpublished material here.
